# Amazing HTTP Logger

Python backend for collecting and persisting HTTP traffic logs generated by software agents running on user devices.

## Overview

The application is responsible for:

- authenticating users and agents
- accepting traffic log payloads from installed agents
- validating and normalizing incoming HTTP metadata
- persisting the data to MongoDB
- exposing a secure API for later analysis and investigation

## Stack

- Python 3.11+
- FastAPI
- Pydantic
- MongoDB
- pytest
- Docker / Docker Compose
- ruff or flake8

## Local development

### 1) Create a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate
```

### 2) Install dependencies

```bash
pip install -r requirements.txt
```

### 3) Configure environment

```bash
cp .env.example .env
```

### 4) Start MongoDB

```bash
docker compose -f docker/docker-compose.yml up -d
```

### 5) Run the app

```bash
uvicorn app.main:app --reload
```

Application URL:

```text
http://127.0.0.1:8000
```

## Validation

```bash
pytest
ruff check .
```

## Containerization

```bash
docker build -f docker/Dockerfile -t amazing-http-logger .
docker run -p 8000:8000 --env-file .env amazing-http-logger
```

## Notes

- keep secrets in environment variables, never in source files
- validate all inbound payloads before persistence
- redact sensitive fields before logging or storage
- keep the API layer thin and delegate business logic to services
